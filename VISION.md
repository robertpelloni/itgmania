# VISION.md

## Project Vision: ITGmania
ITGmania is an advanced cross-platform rhythm game engine (forked from StepMania 5.1).
The goal is to provide a robust, modern, 64-bit capable engine with built-in networking, optimized performance, and powerful Lua-driven UI capabilities (e.g. Simply Love theme).

## Core Concepts
* Cross-platform (Windows, macOS, Linux).
* High performance and accuracy.
* Deeply customizable through Lua themes and NoteSkins.
* Network and profile integration.
